<h1>Alone the Survival Game</h1>
Alone the survival game is a game based on the reality tv show "Alone" where contestants are sent out into very remote places in the wild and have to stay out there for as long as they can without "tapping out" of the game ( leaving the game early ). I'm making this game because it felt like an easy gateway back in to coding with python for an actual project. It's been about 3 years since I've used python, and because this is just a text based game, ( for now ) it feels easy and challenging enough to let me get back into it. I also had the idea for this game because I've been wanting to make a game again for a while, and this is a good simple enough opportunity to do so, and survival games are one of my favorite types of games. Alone is also just a great show in general so, yeah.
<br>
<h1>How do you play the game?</h1>
You can play the game by downloading the file right here on my github, or if you scroll down, you can get it from my itch.io page.<br>
To play the game after grabbing the python file, make sure you have an IDE like VSCode that you can use, or if you have a similar or alternative way to run it, please do. It's as simple as that, and once the game is running, it's pretty self explanatory in terminal which will tell you what to do.
<br>
<h1>The current state of the game</h1>
Right now, the only thing you can do in the game is choose three total items for your inventory. I know, very fun. That's all I have done so far, but I'm still working on it to make it a playable game.
